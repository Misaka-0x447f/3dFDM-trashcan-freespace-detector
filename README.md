# 3D 打印废料桶剩余空间探测器

ESP8266 + HX711 称重传感器 + WS2812B-8 灯带 + SSD1306 OLED。固件将称重传感器的原始读数映射成剩余空间百分比。

## 硬件接线

| 外设 | 引脚 | ESP8266 GPIO | NodeMCU 丝印 |
|---|---|---|---|
| HX711 | DT / DOUT | GPIO5 | D1 |
| HX711 | SCK / CLK | GPIO4 | D2 |
| WS2812B-8 | DIN | GPIO13 | D7 |
| SSD1306 OLED | SCL | **GPIO12** | **D5** |
| SSD1306 OLED | SDA | **GPIO14** | **D6** |

OLED 的 D5/D6 映射是这块 NodeMCU 兼容板的实测结果，`platformio.ini` 已启用 `-DI2C_PINMAP_SWAPPED`。标准 NodeMCU 的 D5/D6 GPIO 映射相反；若换板，重新运行 `i2c_scan` 确认。D1/D2/D7 按标准 NodeMCU GPIO 映射。

## 双点标定

固件用两个实测点定义线性关系：**剩余空间 100% 点**和一个**参考点**（百分比任意，须小于 100），按读数外推其他百分比：

```text
剩余% = 100 - (100 - 参考%) × (当前读数 - 100%点读数) / (参考点读数 - 100%点读数)
```

当前在 `include/config.h` 记录的值：`CAL_RAW_100 = 584098`（空桶）、`CAL_RAW_REF = 643833`、`CAL_PCT_REF = 15`（均为 2026-11-08 实测，30 秒内中位数的均值），斜率约 703 计数/%。两点读数不能相同。若暂时没有读数，可填 `INT32_MIN` 表示未标定，此时 OLED 显示 `--%`、灯带红色闪烁，串口和 OLED 黄区仍显示原始计数。

重新标定步骤：

1. 烧录固件，打开 115200 波特率串口监视器，等待 `[hx711]` 日志。`median` 是连续 5 次读数的中位数。
2. 将传感器保持在已知的剩余空间状态，稳定后记录约 30 秒的 `median`，取均值填入 `CAL_RAW_REF`，对应百分比填入 `CAL_PCT_REF`；需要时同样重测 100% 点填入 `CAL_RAW_100`。
3. 重新烧录。串口启动信息会显示两个标定点，检查显示是否接近实际值。

注意：2026-09-25 的旧 100% 点（627300）与空桶实测相差约 43000 计数，说明传感器零点会漂移，空桶显示偏离 100% 时应重测。称重也只能在桶内废料平均密度和装载方式相近时近似代表剩余**空间**。

## OLED 与灯带

OLED 是黄蓝双色物理分区面板，目前 `U8G2_R2` 旋转 180° 安装。黄区显示 `RAW` 加 5 次读数的中位数；蓝区显示剩余空间百分比。灯带沿用原来的百分比填充和颜色规则。HX711 超时或未标定时显示无效态。

## 编译与烧录

```bash
pio run -e nodemcuv2
pio run -e nodemcuv2 -t upload
pio device monitor -b 115200
```

如需再次确认 OLED 的引脚映射：

```bash
pio run -e i2c_scan -t upload
pio device monitor -b 115200
```

## 代码结构

- `lib/Hx711`：等待 DT 就绪后读取 24 位有符号值，使用 A 通道、增益 128。
- `lib/WeightMapper`：双点线性映射、指数平滑和显示死区。
- `lib/LedBar`：WS2812B-8 百分比灯带。
- `lib/OledView`：SSD1306 OLED 显示。
- `src/main.cpp`：采样、中位数、超时与显示调度。
